# 목요일 발표 자료 준비

자료는 직접 작성·수정한 코드와 mdriver 결과로만 만든다.

## 슬라이드 구성과 자료 위치

| # | 슬라이드 | 자료 | 상태 |
| --- | --- | --- | --- |
| 1 | 타이틀 (바꾼 부분에 관한 짧은 키워드) | 선택한 요인이 정해지면 작성 | 대기 |
| 2 | 책과 AI로 만든 함수와 점수표 → 목표 설정(구두) | `baseline/functions.md`, `baseline/score.md` | 준비됨 |
| 3 | 점수를 높일 수 있는 요인 → 그중 하나를 고른 이유 | `score_factors.md` | 요인 목록 준비됨, 선택 이유 대기 |
| 4 | 무엇을 바꿨는지 | 개선 전/후 코드 비교 (`git diff 018989f -- mm.c`), 개선 후 점수 | 대기 |
| 5 | 교훈 | `../LOG.md`의 "막혔던 점과 해결 방법" | 대기 |

## 기준 버전

- GitHub 커밋 `018989f` — 묵시적 가용 리스트 + first fit
- 점수: **53/100** (내 컴퓨터, 공간 44 + 속도 8)
- 같은 코드를 클라우드에서 재면 59~60점. 공간 점수는 같고 속도 점수만 다르다.
  개선 전/후 비교는 같은 컴퓨터에서 잰 숫자끼리 한다.

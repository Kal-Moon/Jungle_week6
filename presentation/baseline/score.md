# 기준 버전 점수 (점수 개선 전)

- 측정 대상: GitHub 커밋 `018989f` (묵시적 가용 리스트 + first fit)
- 명령: `make` 후 `./mdriver -V`

## 점수 계산 방식 (config.h)

```
Perf index = 60 × util + 40 × min(1, 속도 / 600 Kops)
```

- **util (공간 효율)**: 받아 온 힙 중 실제로 사용자에게 내준 비율. 60점 만점.
- **thru (속도)**: 1초에 처리한 malloc/free/realloc 수. 600 Kops(초당 60만 번) 이상이면 40점 만점.
- 속도는 컴퓨터마다 다르게 나오고, 공간 효율은 어느 컴퓨터에서나 같다.

## 읽는 법

- **공간 점수 44점은 어디서 재도 같다.** 코드가 같으면 힙을 쓰는 방식도 같기 때문이다.
- **속도 점수는 8점(내 컴퓨터) ~ 15점(클라우드)으로 다르다.** 컴퓨터 성능 차이다.
  개선 전/후를 비교할 때는 반드시 **같은 컴퓨터**에서 잰 숫자끼리 비교한다.
- 남은 점수: 공간 쪽 최대 16점, 속도 쪽 최대 32점(내 컴퓨터 기준).
